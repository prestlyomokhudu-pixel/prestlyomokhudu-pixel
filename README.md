## Projects

### ASRI — AI Voice Studio
> Personal AI voice cloning and narration system

A full desktop application for cloning and synthesizing speech using Coqui XTTS v2, with emotion-tagged story narration, RVC voice conversion, and a built-in audio player.

**Tech:** Python · PyQt6 · Coqui XTTS v2 · Kokoro TTS · RVC · FAISS · PyTorch  
**Features:**
- Personal voice cloning from a reference WAV sample
- 6 emotion modes — calm, intense, whisper, warm, energetic, sad
- SSML-inspired text preprocessing with `<break>` and `<prosody>` tags
- RVC voice conversion pipeline
- Waveform visualizer, generation history, background slideshow
- GPU-accelerated (CUDA) with CPU fallback

---

### ASRI Overlay
> Transparent real-time text overlay for streamers and creators

An always-on-top animated overlay that displays typed text with smooth transitions, optional TTS readback, and per-event sound effects — all configurable without touching code.

**Tech:** Python · PyQt6 · Kokoro TTS · Discord Webhooks  
**Features:**
- Transparent, always-on-top window
- Fade, slide, and shimmer flair animations
- Typing indicator with configurable delay
- Global hotkey show/hide
- Optional TTS readback with speed control
- Discord webhook integration
- Full JSON config — no code editing needed

---

### Commission Scout — Discord Bot
> Real-time commission request detector across Discord servers

A Discord bot that monitors every server it's in simultaneously, detects commission-related messages using 60+ keyword patterns, and instantly DMs the owner with a rich embed and jump link.

**Tech:** Python · discord.py · Regex · JSON config  
**Features:**
- Monitors all joined servers simultaneously
- 60+ built-in commission keyword patterns
- Rich embed DM notifications with jump links
- Per-user/channel/server cooldown system
- Configurable ignore lists for channels and servers
- Lightweight — runs on any machine

### Commission Radar
> Multi-platform commission lead scanner

Scans 9 platforms simultaneously for commission requests and surfaces them in one place — Reddit, Bluesky, Mastodon, Cara, Discord boards, Fiverr, Upwork, Facebook, and web search.

**Tech:** Python · SQLite · Reddit API · Bluesky API · Mastodon API · BeautifulSoup · Requests  
**Platforms monitored:**
